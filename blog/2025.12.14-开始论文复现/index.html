    github仓库：tonyzhaozh/act
    项目主页:aloha-2
    核心概念：
    ACT（Action Chunking with Transformers）
    ACT 旨在解决机器人模仿学习中的一个关键难题：如何让机器人不仅学会下一个动作，还能生成一连串平滑、连贯、面向未来的动作序列，以完成复杂的长时间跨度任务
    这篇文章主要想解决的问题：
    一.成本太高 很多机械臂可以完成高精度的任务，但是设备太贵
    二.误差的累计问题 BC（Behavioral Cloning）是好算法，但是会不断的累计误差

    训练流程：
    首先使用 ALOHA 收集人类演示
    接下来，我们训练 ACT 根据当前观察结果预测未来动作序列
    在测试时，我们加载验证损失最低的策略，并在环境中部署它。出现的主要挑战是误差累积，即先前动作的误差导致状态超出训练分布。

    优势：直观地讲，一个动作块可能对应于抓取糖果包装纸的角落或将电池插入插槽。在我们的实现中，我们将块大小固定为 k：每 k 步，智能体接收一个观察结果，生成下一个 k 个动作，并按顺序执行这些动作。这意味着任务的有效范围减少了 k 倍。分块也有助于模拟人类演示中的非马尔可夫行为

    一个简单的动作分块实现可能不是最优的：每 k 步突然加入新的环境观察会导致机器人运动不连贯。为了提高平滑性并避免执行和观察之间的离散切换，我们在每个时间步查询策略。这使得不同的动作分块相互重叠，并且在给定的时间步会有多个预测动作。

    新观察的加入速度由 m 控制，较小的 m 意味着更快的加入速度。我们注意到，与典型的平滑方法不同，该方法将当前动作与相邻时间步的动作进行聚合，从而导致偏差，我们聚合的是同一时间步预测的动作。我们的时间集成方法对这些预测进行加权平均，采用指数加权方案 w= exp(−m ∗ i)，其中 w 是最老动作的权重。

    我们使用 transformers 实现了 CVAE 编码器和解码器，因为 transformers 的设计旨在跨序列合成信息并生成新序列。

    读到这里开始进行仿真。

    MujoCo为物理引擎
    dm_control定义机器人的结构
    OpenGL / EGL 渲染器，模拟机器人的摄像头
    h5py 记录机器人的动作，打包进入文件
    通过采集专家数据，给ACT模型，进行仿真。

    模仿学习仿真的普遍流程：
    1.训练专家演示数据
    在仿真里： 用写好的代码（脚本）控制机器人，完美地做50遍任务。
    在真机上： 用人手拿着主手（遥操作），控制机器人做50遍任务。
    核心目的： 生产数据。AI 不懂物理，它只认数据。
    启示： 数据的质量决定了 AI 的上限。 如果刚才脚本里机器人手抖了，或者抓空了，AI 也会学会手抖和抓空
    2.策略训练
    动作： 把刚才存下来的 .hdf5 文件喂给神经网络（ACT）。
    原理： 监督学习。让 AI 看着图片（Input），去猜刚才脚本做了什么动作（Label），猜不对就罚它（Loss），直到它猜得和脚本一模一样。
    3.策略评估
    动作： 关掉脚本，换上训练好的 AI 模型来控制机器人。
    核心目的： 看 AI 是不是真的学会了，还是只是背下了答案。

    仿真成功之后，代码不需要修改就可以部署到机器人（把真机的数据调成.hdf5的格式），接下来只剩下硬件调试

    .hdf5文件的内容：
    /observations/images (图片数据：用来模拟眼睛)
    /observations/qpos (关节角度：用来模拟本体感觉)
    /action (动作指令：老师傅的操作)

    训练流程：
    一.安装环境和下载代码
    1. 下载仓库代码
    cd ~

    如果网络不好，建议在Windows下载zip包，通过 explorer.exe . 拖进去解压

    git clone https://github.com/tonyzhaozh/act.git  
cd act
    2. 创建环境

    创建环境 (指定 Python 3.8.10)

    bash conda create -n aloha python=3.8.10 # 激活环境 conda activate aloha
    1. 安装基础依赖

    换清华源 (可选，但推荐)

    pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple

    安装 PyTorch 和其他库

    pip install torchvision torch pyquaternion pyyaml rospkg pexpect mujoco==2.3.7 dm_control==1.0.14 opencv-python matplotlib einops packaging h5py ipython
    2. 安装DETR子模块
    bash cd ~/act/detr pip install -e .

    如果报错缺少 setup.py，说明要在 act 根目录下找 detr 子文件夹

    1. 安装系统级图形库 (解决 MuJoCo 报错) bash sudo apt update sudo apt install -y libosmesa6-dev libgl1-mesa-glx libglfw3 patchelf

    2. 手动下载ResNet（防止网络卡顿） 这是为了解决 PyTorch 自动下载模型太慢的问题。

    3. 在 Windows 下载文件：https://download.pytorch.org/models/resnet18-f37072fd.pth

    4. 把文件拖入 act 文件夹。
    5. 在终端执行移动操作：

    创建隐藏目录

    mkdir -p ~/.cache/torch/hub/checkpoints/

    移动文件 (假设文件在当前目录下)

    mv resnet18-f37072fd.pth ~/.cache/torch/hub/checkpoints/ 1. 修改配置文件
    bash nano constants.py DATA_DIR = '<put your data dir here>' 把里面的内容修改成 DATA_DIR = './data'

    二.仿真运行
    1.采集专家数据
    ```bash cd ~/act

    采集 50 条数据

    python3 record_sim_episodes.py \
    --task_name sim_transfer_cube_scripted \
    --dataset_dir data/sim_transfer_cube_scripted \
    --num_episodes 502.开始训练bash
    python3 imitate_episodes.py \
    --task_name sim_transfer_cube_scripted \
    --ckpt_dir ckpt/my_first_train \
    --policy_class ACT \
    --kl_weight 10 \
    --chunk_size 100 \
    --hidden_dim 512 \
    --batch_size 8 \
    --dim_feedforward 3200 \
    --num_epochs 2000 \
    --lr 1e-5 \
    --seed 0```
    3.推理验证.

    注意多了 --eval 参数，且换了 seed

    python python3 imitate_episodes.py \ --task_name sim_transfer_cube_scripted \ --ckpt_dir ckpt/my_first_train \ --policy_class ACT \ --kl_weight 10 \ --chunk_size 100 \ --hidden_dim 512 \ --batch_size 8 \ --dim_feedforward 3200 \ --num_epochs 2000 \ --lr 1e-5 \ --seed 2 \ --eval
    三.查看结果 1.打开任意文件夹。
    2.在地址栏输入：\wsl$ 并回车。
    3.路径导航：Ubuntu -> home -> jbs -> act -> ...
